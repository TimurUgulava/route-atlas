Вставляется в промпт как есть, блоком STYLE:

```
{английская формула из студии стиля, например:
hand-painted semi-realistic aerial illustration for a premium travel atlas —
textured treetops across ridges, turquoise shallows along sandy coves, warm
soft morning light, painterly brush texture. Elegant, editorial, matte.}
```

## Параметры

| Параметр | Значение |
|----------|----------|
| Цвет маршрута | `{#RRGGBB}` |
| Пропорция по умолчанию | `{16:9}` |
| Толщина линии | одна непрерывная, слегка приподнята над рельефом |
| Маркеры точек | круглые, цвета маршрута, тонкое белое кольцо; старт и финиш крупнее |
| Капсулы подписей | белые, скруглённые, мягкая тень |
| Цвет текста | `{#303036}` |
| Высота капсулы | `{0.031}` от высоты кадра (флаг `--font-size-ratio`) |
| Шрифт | `{системный по умолчанию или путь}` |
| Топонимов на карту | `{4–6}` |
| Виньеток на карту | `{5–8}`, каждая 4–6% ширины кадра, без подписей |
| Атмосфера | `{туман/дымка/чистый свет — и правило: по реальной погоде дня}` |

## Правила, которые не меняются

1. Карта генерится **без текста**; подписи ставит `finalize.py`.
2. Эталон подаётся стилевым референсом **только в первой генерации** карты.
3. Правки — точечные, по одной за вызов, без референса.
4. Виньетка — только реальное событие поездки, с источником.
