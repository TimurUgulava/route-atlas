# Паспорт стиля карт — {имя автора или проекта}

Собран в студии стиля {дата}. Эталон: `{файл-эталон.png}` рядом с этим файлом
(для сравнения глазами; в генерацию эталон НЕ подаётся — стиль передаётся

## Формула стиля

Вставляется словами в блок {STYLE} шаблона покраски (prompt-base.md):

```
{английская формула из студии стиля, например:
hand-painted semi-realistic aerial illustration for a premium travel atlas —
textured treetops across ridges, turquoise shallows along sandy coves, warm
soft morning light, painterly brush texture. Elegant, editorial, matte.}
```

## Параметры

| Параметр | Значение |
|----------|----------|
| Цвет маршрута | `{#RRGGBB}` — он же в route-style.json (fill_rgb) |
| Пропорция по умолчанию | `{16:9}` |
| Пластика линии и точек | `route-style.json` рядом (толщина, размеры точек, тень) |
| Палитра terrain-базы | `{нет / palette.json рядом}` (нужна для карт без покраски) |
| Капсулы подписей | белые, скруглённые; цвет текста `{#303036}` |
| Кегль подписей | `{0.031–0.037}` от высоты кадра (флаг `--font-size-ratio`) |
| Шрифт | `{системный по умолчанию или путь}` |
| Топонимов на карту | `{4–6}` |
| Виньеток на карту | `{5–8}`; ширины в placement.json, ориентиры в production.md |
| Атмосфера | `{туман/дымка/чистый свет — и правило: по реальной погоде дня}` |

## Правила, которые не меняются

1. Карта генерится **без текста**; подписи ставит `finalize.py`.
2. Покраска базы — стиль **словами**, референс-картинка не передаётся никогда.
3. Виньеткам референсом — только покрашенная база текущей карты.
4. Гейты (изотропия привязки, дрейф покраски) не обходятся.
5. Виньетка — только реальное событие поездки, с источником.
