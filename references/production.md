# Производство карты v2 — полный протокол

Этап B из SKILL.md, подробно: команды, форматы файлов, чек-листы, грабли.

Сквозной пример имён файлов одной карты (соглашение, не догма):

```
screenshot.jpg                исходник от человека
anchors.json → georef.json    геопривязка
geometry.json                 оцифрованный маршрут и точки
terrain.png + landmask.npy    слой 1: настоящий рельеф
painted.png                   слой 2: покраска движком
base-approved.png             утверждённая база (= painted или terrain)
with-route.png                + слой 3: маршрут
vignettes/ + placement.json   спрайты виньеток и их расстановка
full.png                      + слой 4: виньетки
labels.json → final.png       + слой 5: подписи (finalize.py)
vignettes-final.json          отчёт об источниках виньеток
```

---

## Шаг 2 подробно: геопривязка и оцифровка

Это единственный ручной труд в v2 (10–15 минут), и на нём стоит вся точность.

**2.1 Сетка.** Скопируй скриншот и нанеси сетку 100 px с подписанными делениями
(PIL, десять строк кода). По ней снимаются пиксели.

**2.2 Якоря.** Выбери 8–12 населённых пунктов, разбросанных по кадру (не кучей
в одном углу). Пиксель — центр названия на карте. Координаты каждого города
**проверь поиском** — не бери из памяти: одна перепутанная деревня из
одноимённых портит подгонку (её, впрочем, отсев поймает). Собери anchors.json:

```json
{
  "anchors": {
    "Переславль-Залесский": {"px": [755, 163], "lat": 56.7360, "lon": 38.8527}
  },
  "plate": [638, 118, 2200, 997]
}
```

`plate` — рамка самой карты на скриншоте, без панелей браузера и боковых меню:
всё, что внутри неё, станет кадром будущей карты. UI-мусор в v2 не мешает —
из скриншота берутся только координаты, картинка целиком в генерацию не идёт.

**2.3 Подгонка:** `python3 scripts/fit_georef.py --anchors anchors.json --out
georef.json`. Читай вывод: остатки по якорям (норма — до ~30 px: это точность
снятия названия, не привязки), что выброшено, изотропия. Гейт изотропии
(≤ 1%) — встроенный детектор ошибок: у веб-карт пиксель квадратный, и если
масштабы по осям разошлись, какие-то якоря сняты неверно. Скрипт остановится
сам — не обходи его.

**2.4 Маршрут.** По той же сетке сними полилинию (каждые ~30–50 px по линии,
на поворотах чаще) и точки человека в geometry.json:

```json
{
  "route": [[0.879, 0.694], [0.878, 0.688], ...],
  "waypoints": {"Владивосток": [0.066, 0.603], "бухта Тачингоуза": [0.879, 0.694]}
}
```

Координаты нормированные (0..1) **внутри рамки plate**. Ломаная может быть
грубой — draw_route сгладит сплайном. Самопроверка обязательна: нарисуй свою
полилинию тонкой линией поверх скриншота и сравни — линия должна лечь на линию.

## Шаг 4 подробно: база

**4.1 Рельеф:**

```bash
python3 scripts/render_terrain.py --georef georef.json \
    --out terrain.png --landmask landmask.npy \
    [--palette palette.json] [--width 2752] [--zoom 11] [--zex 3.2]
```

- `--zoom` — детальность высот: 11 для областей и регионов, 12–13 для коротких
  маршрутов (< 100 км), иначе рельеф выйдет обмылком.
- `--zex` — вертикальное преувеличение: 3.2 для холмов и сопок; для по-настоящему
  горных мест снижай до 2–2.5, для равнин можно поднять до 4.
- Скачивание — только открытые тайлы высот, без ключей; кэшируются во временной
  папке, повторный прогон мгновенный.

Проверь глазами против скриншота: берег, реки, взаимное положение точек.
Ошибка здесь — это ошибка привязки, возвращайся к шагу 2.

**4.2 Покраска.** Промпт — по [prompt-base.md](prompt-base.md): шаблон
«retexture, locked stencil» + формула стиля СЛОВАМИ из паспорта пользователя.
Вход — terrain.png, режим редактирования. Три запрета, которые не обсуждаются:

- ⛔ референс-картинка (эталон, чужая карта) не передаётся — перетащит свою
  географию. Живой замер: с референсом IoU 0.37, без — 0.84;
- никакого текста, маршрута, виньеток — это другие слои;
- один проход. Цепочек правок картинки в v2 нет.

**4.3 Гейт:** `python3 scripts/drift_check.py --painted painted.png --landmask
landmask.npy`. PASS → дальше. FAIL → один-два повтора покраски с
переформулировкой; не помогло — откат на terrain.png (честно скажи человеку:
«художественную покраску движок не удержал, собираю на точной базе»).
Для континентальных маршрутов без моря скрипт сам скажет, что проверка по воде
не работает — тогда сверка глазами по рекам и озёрам.

**4.4 Утверждение.** Покажи базу. После «ок» сохрани `base-approved.png`
**в размере финального кадра** (движок отдаёт ~1376 — растяни Lanczos до
ширины terrain.png, либо прогони Real-ESRGAN, если нужна печать). Дальше база
не меняется никогда.

## Шаг 5 подробно: слои

**5.1 Маршрут:**

```bash
python3 scripts/draw_route.py --base base-approved.png --geometry geometry.json \
    --style route-style.json --out with-route.png
```

Пластика (толщина, цвета, размер точек, сила тени) — из route-style.json
пользователя, собранного в студии. В команде её не переопределить — это
сознательно: стиль меняется в файле, по решению владельца, и тогда одинаково
для всех следующих карт.

**5.2 Виньетки.** Генерация по одной, в одном диалоге (единство руки),
шаблон — в prompt-base.md. Референсом — base-approved.png. Обязательные
элементы промпта: PURE WHITE background · NO white sticker border · no outline ·
no cast shadow · для протяжённых объектов (мост, поезд, набережная) — замкнутая
композиция «fits fully inside the frame, nothing cut by edges».

Расстановка:

```json
[
  {"file": "vign-car.png",   "x": 0.360, "y": 0.428, "width": 250},
  {"file": "vign-cabin.png", "x": 0.800, "y": 0.598, "width": 215}
]
```

`x, y` — центр виньетки (нормированные), `width` — ширина в px эталонного
кадра 2752 (масштабируется автоматически). Ориентиры размера: транспорт
~230–300, зверь ~200–265, здание ~190–220, мелкий предмет ~150–200.

```bash
python3 scripts/place_vignettes.py --base with-route.png \
    --placement placement.json --sprites vignettes/ --out full.png
```

Скрипт сам вырежет фон (заливкой от краёв — белые части объекта не пострадают),
подгонит цвет, положит контактную и падающую тени по свету сцены и сплавит швы
лёгким живописным фильтром (для графичных стилей его отключает `--no-melt`).

Проверь после сборки: виньетки не перекрывают линию и точки (кроме осознанного
«машина едет по дороге»), не вылезают за кадр, не столпились.

**5.3 Подписи.** Якоря капсул — **истинные точки маршрута из geometry.json**
(не «где на глаз красиво»):

```json
[
  {"text": "Москва", "anchor": [0.424, 0.820], "side": "below"},
  {"text": "Переславль-Залесский", "anchor": [0.613, 0.349], "side": "left"}
]
```

- `side` — с какой стороны лечь капсуле: `left / right / above / below`;
  выбирай сторону от линии маршрута, а не поверх неё.
- `gap` — зазор (default 0.006); ширину капсулы знает только скрипт, поэтому
  зазор у всех подписей одинаковый — ряд стоит ровно.
- `dot: true` больше не нужен — точки рисует draw_route.

```bash
python3 scripts/finalize.py --input full.png --labels labels.json \
    --output final.png --font-size-ratio <из паспорта> [--grid] [--also-half] [--no-upscale]
```

`--grid` — черновой прогон с сеткой для подбора координат. `--no-upscale` —
если база уже в целевом размере (обычный случай v2). Кегль: с точками
draw_route обычно хорош 0.033–0.037 — точный записан в паспорте пользователя.

Проверь кроп 1:1: текст хрустит, написание всех названий верное.

## Грабли v2: симптом → причина → лечение

| Симптом | Почему | Что делать |
|---------|--------|-----------|
| **Изотропия > 1% в fit_georef** | якорь снят не с того места или город-тёзка | перепроверить пиксели и координаты; скрипт не обходить |
| **Рельеф не совпадает со скриншотом** | ошибка привязки (bbox не тот) | назад к шагу 2; render_terrain не виноват — он рисует то, что в georef |
| **Рельеф — обмылок без деталей** | zoom тайлов мал для короткого маршрута | `--zoom 12` или 13 |
| **Горы выглядят плоскими / равнина горбатая** | вертикальное преувеличение не по местности | `--zex` вниз/вверх, перегон секунды |
| **drift_check FAIL** | покраска перерисовала берег; чаще всего в неё попал референс-картинка | убрать референс; переформулировать; после двух кругов — откат на terrain |
| **Покраска дорисовала «дорожки» в долинах** | модель любит вести тропинки по ложбинам | в Forbidden промпта: «no roads or trails of any kind» |
| **Небо и горизонт на покраске** | модель уводит карту в пейзаж | «top-down view preserved, no sky, no horizon» уже в шаблоне — проверь, что не выкинул |
| **Текст на покраске или виньетке** | модели пишут сами, особенно кириллицей, с опечатками | перегенерация; запрет текста в шаблоне капсом; подписи всё равно ставит только finalize.py |
| **Виньетка с белой каймой-стикером** | модель рисует «наклейку» | «NO white sticker border, NO outline stroke» в промпте; уже в шаблоне |
| **Протяжённая виньетка обрезана краем кадра** | объект не влез в квадрат генерации | требовать замкнутую композицию: «fits fully inside the frame with generous margins, both ends visible» |
| **Виньетка «парит» над картой** | не посажена в сцену | сажать к маршруту; тени кладёт place_vignettes — проверь, что не отключил melt без причины |
| **Виньетка перекрыла линию/точку** | позиция в placement.json | сдвинуть числа, пересборка секунды |
| **Линия с зазубринами** | рисуется PIL-ломаной вместо draw_route | пользоваться draw_route: там штампование по сплайну |
| **Линия слишком угловатая/слишком спрямлённая** | сглаживание сплайна | `spline_smoothing_per_point` в route-style.json: меньше — точнее к оцифровке, больше — плавнее |
| **Подписи разъехались от точек** | якоря сняты с картинки на глаз | якоря = точки из geometry.json, всегда |
| **Кегль не как в прошлых картах** | забыт паспорт | `--font-size-ratio` из паспорта, не по вкусу сессии |

## Правки: таблица цен

Показывай её человеку — он привык, что правки дороги, а здесь они бесплатны:

| Просьба | Действие | Цена |
|---------|----------|------|
| линия толще/тоньше, точки крупнее | route-style.json + draw_route + place_vignettes + finalize | секунды |
| подвинуть/масштабировать виньетку | placement.json + place_vignettes + finalize | секунды |
| заменить/добавить виньетку | одна генерация + place_vignettes + finalize | одна картинка |
| подпись: текст/сторона/кегль | labels.json + finalize | секунды |
| атмосфера/цвет базы | новый проход покраски + drift_check + все слои | один проход |
| другой кусок маршрута | новый скриншот → с шага 2 | новая карта |

Порядок пересборки слоёв всегда одинаковый: draw_route → place_vignettes →
finalize. Меняешь нижний слой — верхние перегоняются следом (это секунды).
