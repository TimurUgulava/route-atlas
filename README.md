# route-atlas

Скилл для Claude Code, который превращает обычный скриншот маршрута с карт
в иллюстрированную псевдо-3D карту: настоящий рельеф местности, линия маршрута
вашего цвета, аккуратные подписи и маленькие картинки-виньетки того, что
случилось в поездке — заправка, где кончился бензин; бухта, где вы купались;
дом, где ночевали.

Стиль вы собираете свой. Скилл ведёт через студию стиля, запоминает результат
паспортом — и все следующие карты выходят одинаковыми по почерку.

---

## Зачем это, если есть генераторы картинок

Попросить нейросеть «нарисуй красивую карту маршрута» может кто угодно, и получит
она красивый вымышленный край: берег не тот, маршрут кольцом, подписи с опечатками.
Ценность здесь не в промпте, а в протоколе вокруг модели:

- **География берётся с вашего скриншота.** Карта рисуется поверх него в режиме
  редактирования, а не выдумывается по описанию.
- **Карта генерится вообще без текста.** Названия ставятся программно, ровным
  шрифтом. Модели врут в надписях, особенно в кириллице, и лечится это не
  уговорами, а тем, что текст рисует не модель.
- **Виньетка без источника не рисуется.** Ассистент спрашивает, что и где было,
  и в конце отчитывается, откуда взял каждую картинку. На карте вашего маршрута
  не появится «кораблик для красоты».
- **Правки точечные.** Одна правка за раз, с фиксацией всего остального —
  иначе каждая перегенерация двигает то, что уже нравилось.
- **Разрешение поднимается классическим апскейлером**, а не «нейро-улучшайзером»,
  который заодно перерисует вашу карту.

## Что нужно

**Обязательно:** Python 3.8+, библиотеки `pillow`, `numpy`, `requests`
(`pip3 install pillow numpy requests`).

**Движок генерации — любой из:**
- уже подключённый в вашем клиенте image-MCP (Nano Banana, Gemini и подобные) —
  тогда ключи не нужны вовсе;
- свой ключ Google AI — у Gemini есть бесплатный тариф;
- ключ OpenAI (запасной путь: картинка красивая, но география поплывёт).

Главное требование к движку — он должен уметь **редактировать поданную картинку**,
а не только рисовать с нуля. Подробное сравнение — в
[references/backends.md](references/backends.md).

**Желательно:** [Real-ESRGAN](https://github.com/xinntao/Real-ESRGAN/releases)
для повышения разрешения; `pip3 install keyring fonttools` — хранение ключа
в системном хранилище секретов и проверка шрифта на нужные буквы.

## Установка

```bash
git clone https://github.com/<ваш-аккаунт>/route-atlas.git ~/.claude/skills/route-atlas
cd ~/.claude/skills/route-atlas
python3 scripts/check_setup.py
```

Диагностика покажет, что уже есть и чего не хватает, с готовыми командами.
Если нет ключа и нет MCP:

```bash
python3 scripts/setup_key.py --backend gemini
```

Ключ вводится вами, в невидимом поле, проверяется у сервиса и кладётся
в системное хранилище секретов (или в `.env` с правами 600, закрытый от git).

## Как пользоваться

Скажите ассистенту: **«нарисуй карту маршрута»** — и приложите скриншот маршрута
из Яндекс.Карт, Google Maps или OpenStreetMap.

Дальше он проведёт вас по шагам: соберёт точки и события, покажет спецификацию
на утверждение, нарисует, даст поправить, поставит подписи и поднимет разрешение.
В первый раз добавится студия стиля — минут пятнадцать, один раз в жизни.

Скрипты можно звать и руками:

```bash
# сгенерировать (если нет MCP)
python3 scripts/generate.py --prompt "..." --input screenshot.jpg \
    --aspect 16:9 --output map.png

# подписи + разрешение
python3 scripts/finalize.py --input map.png --labels labels.json \
    --output final.png --also-half
```

Файл подписей — координаты в долях от размера кадра:

```json
[
  {"text": "Владивосток", "x": 0.077, "y": 0.543, "dot": [0.075, 0.505]},
  {"text": "село Лазо",   "x": 0.794, "y": 0.339}
]
```

## Об исходниках карт

Скриншот Яндекс.Карт или Google Maps — их материал, и правила этих сервисов
ограничивают производные работы. Для личного альбома на это обычно смотрят сквозь
пальцы, но если карта пойдёт в публикацию, лучше снять исходник с
[OpenStreetMap](https://www.openstreetmap.org): там производные разрешены при
указании источника — достаточно подписи «© OpenStreetMap contributors».

Скилл сам напомнит об этом, когда речь зайдёт о публикации.

## Безопасность

Ключи не пересылаются в переписке, не передаются аргументами команд (поэтому
такого флага в скриптах нет вовсе) и не выводятся на экран. Ассистенту доступен
только факт «подключено / не подключено». Если ключ где-то засветился — отзовите
его в консоли сервиса и выпустите новый.

## Структура

```
SKILL.md                    протокол: движок → студия стиля → производство карты
references/
  style-studio.md           как собрать свой стиль и сохранить паспортом
  production.md             промпт, чек-листы, формулы правок, грабли моделей
  backends.md               сравнение движков, безопасность ключей, апскейлер
scripts/
  check_setup.py            что установлено, чего не хватает
  setup_key.py              безопасное подключение ключа
  generate.py               генерация через доступный API
  finalize.py               программные подписи + повышение разрешения
assets/
  style-passport-template.md шаблон паспорта стиля
```
